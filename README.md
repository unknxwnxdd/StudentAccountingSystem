# StudentAccountingSystem

Проєкт програмної системи обліку студентів.

Стан проєкту: навчальний прототип предметної логіки.

Призначення:
Система призначена для обліку студентів, академічних груп, успішності та відвідування. Передбачені ролі: працівник деканату, викладач, студент та адміністратор.

Планована архітектура:
Трирівнева клієнт-серверна: Presentation / Business Logic / Data Access. Вебінтерфейс і база даних є частиною майбутньої реалізації.

Використані технології
- Git та GitHub — контроль версій і спільна робота;
- Markdown — документація;
- Python 3.10+ (стандартна бібліотека) — навчальний прототип бізнес-логіки;
- `unittest` — автоматизовані модульні тести.

Запуск навчального прототипу:
Після додавання модуля `src/student_accounting.py`:
```bash
python -m src.demo
python -m unittest discover -s tests -v
```
