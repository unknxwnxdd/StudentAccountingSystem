# План тестування

Перевірки на основі `unittest`:
- додавання та отримання запису студента;
- відхилення дубльованого ID;
- відхилення порожнього імені;
- після додавання функції фільтрації — відбір за групою;
- після реалізації Issue — пошук за прізвищем.

Запуск:

```bash
python -m unittest discover -s tests -v
```
