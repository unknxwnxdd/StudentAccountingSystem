# Область застосування

Програмна система призначена для обліку студентів закладу вищої освіти.

Основні функції майбутньої системи:

* облік студентів і академічних груп;
* внесення результатів навчання та відвідування;
* пошук, фільтрація та формування звітів;
* автентифікація й рольовий доступ;
* особистий кабінет студента.
